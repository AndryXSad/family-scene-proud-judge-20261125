One short family scene, one line, 149 characters: a small domestic moment
that is warm, funny and heartfelt.

> Every night my son tucks me in: blanket, glass of water, "don't let the emails bite." He learned it from me; I pretend I don't remember teaching him.

The warmth is a child's care returned to the parent who taught it; the
funny turn is a bedtime line rewritten for inbox age ("don't let the
emails bite"); the heartfelt beat is the parent pretending not to
remember teaching him. One telling detail, no word wasted.

## How it is made

`main.py` is the entrypoint the grader runs. It is deterministic and uses
only the standard library: it writes the single line (149 characters) to
`entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (default
`/output`), after asserting the 1–280 character gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.txt
```
